tools_AI執筆のソシャゲ新着情報
================================

このフォルダはGitHub Pages公開用です。

構成
----
index.html
style.css
app.js
data/posts.json
data/posts.js
posts/                  毎日の記事HTML
.nojekyll

初期状態では記事はありません。
XInfoCollectorのブログ連携を設定して日報を実行すると、
以下が自動更新されます。

- posts/YYYY-MM-DD.html
- data/posts.json
- data/posts.js
- タグ件数
- 月別アーカイブ
- トップページの記事一覧

公開リポジトリには、Xログイン情報・Ollama会話・ntfyトピック・
XInfoCollector本体・GitHub認証情報は入りません。
